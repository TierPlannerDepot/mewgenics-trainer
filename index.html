Features

Everything you need in one overlay

Six battle-tested modules built specifically around Mewgenics' breeding and combat loops.

🛡️

Godmode

Freeze incoming damage for every cat in your roster. Your breeders and champions stay standing through the toughest encounters.

🎒

Infinite Items

Lock consumables and crafting materials at a fixed count so you never run dry mid-run. Applies to inventory stacks instantly.

📊

Stat Editor

Fine-tune HP, attack, speed and breeding traits per cat with a live editor. Values write straight to memory — no save editing required.

🪙

Gold Multiplier

Scale every gold pickup and reward from 1× up to 100×. Perfect for testing late-game builds without the grind.

⏱️

Instant Breed Cooldowns

Remove the wait between breeding cycles. Queue up generations back-to-back and iterate on bloodlines in minutes.

🪟

External Overlay

Runs as a separate window with a hotkey-hide toggle. No DLL injection, no game-file patching, and clean uninstall.

How it works

Up and running in under a minute

No installers, no dependencies, no account. Download, launch, and toggle.

1

Download the trainer

Grab the latest release from gitscore.cc and extract the ZIP anywhere on your machine — a portable folder is enough.

2

Launch Mewgenics, then the overlay

Start the game first, then run the trainer as administrator. It auto-detects the Mewgenics process and attaches externally.
